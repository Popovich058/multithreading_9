# Поиск максимального значения в слайсе: однопоточный и многопоточный подходы

Программа на языке Go для поиска максимального значения в слайсе целых положительных чисел. Реализованы два подхода: однопоточный (последовательный) и многопоточный (с использованием горутин) — для сравнения производительности при работе с большими объёмами данных (например, 10 миллионов элементов).

## Функциональность

Программа выполняет следующие задачи:
1. Генерирует слайс случайных положительных целых чисел заданного размера.
2. Находит максимальное значение в слайсе в **одном потоке**.
3. Находит максимальное значение в слайсе **в 8 горутинах** (разделяя слайс на 8 частей).
4. Измеряет и выводит время выполнения для обоих подходов в микросекундах.
5. Содержит unit‑тесты для ключевых функций.

## Ключевые функции

### `generateRandomElements(size int) []int`
Генерирует слайс из `size` случайных положительных целых чисел. Обрабатывает крайние случаи (например, `size = 0`).

### `maximum(slice []int) (int, error)`
Находит максимальное число в переданном слайсе. Возвращает максимум и ошибку (если слайс пуст). Обрабатывает все крайние случаи:
* пустой слайс;
* слайс с одним элементом;
* обычный слайс.

### `maxChunks(slice []int) (int, error)`
Находит максимум, разделяя слайс на 8 частей и обрабатывая каждую часть в отдельной горутине:
1. Делит слайс на 8 равных частей (или почти равных).
2. Запускает 8 горутин с помощью `sync.WaitGroup`.
3. В каждой горутине находит максимум своей части слайса.
4. Собирает 8 промежуточных максимумов в новый слайс.
5. Находит и возвращает максимум из этих 8 значений.
6. Обрабатывает ошибки (например, пустой слайс).

### `main()`
Основная функция:
1. Создаёт слайс данных с помощью `generateRandomElements()` (размер задаётся константой `SIZE`).
2. Измеряет время выполнения `maximum()` (однопоточный подход).
3. Измеряет время выполнения `maxChunks()` (многопоточный подход).
4. Выводит результаты (максимумы и время выполнения) в консоль.
